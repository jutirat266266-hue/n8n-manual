4. สร้าง Workflow แรก (Step-by-Step)

ทดลองสร้าง Workflow เพื่อส่งและแปลงข้อมูลข้อความอย่างง่าย:

1

กดปุ่ม + Add first step บน Canvas ➔ เลือก When clicking 'Test workflow' (Manual Trigger)

2

คลิกจุดวงกลม Output ฝั่งขวาของ Manual Trigger ลากสายเชื่อมต่อออกมา แล้วพิมพ์ค้นหา Edit Fields (Set)

3

ในหน้าต่างตั้งค่า Edit Fields ให้กำหนดค่าดังนี้:

  • ในหัวข้อ Fields to Set กดปุ่ม + Add Field ➔ เลือก String
  • ช่อง Name ใส่คำว่า: project_name
  • ช่อง Value ใส่คำว่า: n8n OCR System
7

กดปุ่ม Execute Node ด้านขวาบน ผลลัพธ์ในฝั่ง Output จะแสดงข้อมูล JSON:

{
  "project_name": "n8n OCR System"
}
