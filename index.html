1. n8n คืออะไร? & สถาปัตยกรรม

n8n เป็นแพลตฟอร์ม Workflow Automation แบบ Fair-Code ที่ช่วยเชื่อมต่อแอปพลิเคชันและบริการต่าง ๆ เข้าด้วยกันโดยเน้นการจัดการข้อมูลได้อย่างอิสระและมีความปลอดภัยสูง

2. คำศัพท์ & ส่วนประกอบเมนู

ทำความเข้าใจองค์ประกอบสำคัญ เช่น Workflow, Node, Credentials, Execution และ Trigger เพื่อการออกแบบระบบอย่างมีประสิทธิภาพ

3. เริ่มต้นใช้งาน Workspace

แนะนำภาพรวมพื้นที่ทำงาน (Canvas) การจัดการ Node และการใช้เครื่องมือซูม/จัดระเบียบภาพรวม Workflow

4. สร้าง Workflow แรก (Step-by-Step)

ทดลองสร้าง Workflow เพื่อส่งและแปลงข้อมูลข้อความอย่างง่าย:

1

กดปุ่ม + Add first step บน Canvas ➔ เลือก When clicking 'Test workflow' (Manual Trigger)

2

คลิกจุดวงกลม Output ฝั่งขวาของ Manual Trigger ลากสายเชื่อมต่อออกมา แล้วพิมพ์ค้นหา Edit Fields (Set)

3

ในหน้าต่างตั้งค่า Edit Fields ให้กำหนดค่าดังนี้:

  • ในหัวข้อ Fields to Set กดปุ่ม + Add Field ➔ เลือก String
  • ช่อง Name ใส่คำว่า: project_name
  • ช่อง Value ใส่คำว่า: n8n OCR System
7

กดปุ่ม Execute Node ด้านขวาบน ผลลัพธ์ในฝั่ง Output จะแสดงข้อมูล JSON:

{
  "project_name": "n8n OCR System"
}

5. เจาะลึกชนิด Trigger Node

เรียนรู้ประเภทของ Trigger ทั้งแบบ Webhook, Schedule, App Events และ Manual เพื่อเลือกใช้ให้เหมาะกับโจทย์งาน

6. โครงสร้าง Action & Logic Node

การใช้ Node ประเภทเงื่อนไข เช่น If, Switch และการวนลูป Loop Over Items เพื่อประมวลผลข้อมูลหลายรายการ

7. การแมปข้อมูล & Expression

การใช้ไวยากรณ์ JavaScript Expression และการดึงข้อมูลจาก Node ก่อนหน้าด้วยโครงสร้าง {{ $json.fieldName }}

8. วิธีทดสอบ & ตรวจ Error

เทคนิคการทดสอบ Workflow ทีละ Node การอ่าน Log ข้อผิดพลาด และการตรวจสอบผลลัพธ์ผ่านตัวแปร Output

9. การตั้งเวลาอัตโนมัติ

การตั้งเวลาให้ระบบทำงานโดยอัตโนมัติด้วย Cron Expression หรือ Schedule Trigger

10. ระบบ Error Handling

การจัดการเมื่อ Workflow เกิดข้อผิดพลาด เช่น การสร้าง Error Trigger และส่งการแจ้งเตือนไปยัง LINE Notify หรือ Email

11. การเชื่อมต่อ Webhook Node

การเปิดรับข้อมูลจากระบบภายนอกผ่าน HTTP POST/GET Requests เพื่อรับส่งค่าแบบ Real-time

12. การเปิดใช้งานจริง (Active)

ขั้นตอนการสวิตช์สถานะ Workflow เป็น Active เพื่อเปิดระบบรันใน Production พร้อมการเปิด/ปิดบันทึก Execution Data
